## 如何添加新内容

1. 新建文件夹放页面，例如 `my-entry/index.html`。
2. 在根目录 `index.html` 的 `<script id="entries">` JSON 数组最前面加一个对象（字段见文件顶部注释的模板），同时在上方目录对应类型下加一行。
3. 提交并推送到 `main`，约 1 分钟后生效。
